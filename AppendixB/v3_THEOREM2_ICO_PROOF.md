# Direct full-ICO upper-bound certificate for Theorem 2

This note proves the upper bound

```math
F_{\max}^{\mathrm{ICO}}(3;\mathcal N_\gamma)
\leq
\frac{2-\gamma}{24}
\left[12+(8\sqrt{2}-9)\gamma+(3-8\sqrt{2})\gamma^2\right].
```

The explicit parallel construction in the manuscript proves achievability
and is not checked here.

## 1. Direct expansion of the four performance blocks

Write

```math
G^\dagger\bar C G
=\bigoplus_{k=0}^{8}(I_{d_k}\otimes H_k).
```

Let $\mathcal U$ denote the unitary channel generated by $U$, and set

```math
J^{\mathcal U}=\lvert U\rangle\!\rangle\langle\!\langle U\rvert,
\qquad
\Phi_U=(J^{\mathcal U})^T
=\lvert U^*\rangle\!\rangle\langle\!\langle U^*\rvert,
\qquad
D=\frac{I_4}{2}.
```

Here $D$ is the Choi operator of the completely depolarizing qubit channel,
so the Choi operator of one noisy call is

```math
J^{\mathcal N_\gamma\circ\mathcal U}
=(1-\gamma)J^{\mathcal U}+\gamma D.
```

Inserting three copies into the strategy gives the output Choi operator

```math
J^{\mathcal E_U}
=\bar C*\left(J^{\mathcal N_\gamma\circ\mathcal U}\right)^{\otimes3}.
```

With the unnormalized Choi convention, its channel fidelity with the target
unitary is defined as

```math
\frac{1}{d^2}\,\mathrm{Tr}(J^{\mathcal E_U}J^{\mathcal U}).
```

The factor $1/d^2$ makes the fidelity of $\mathcal U$ with itself equal to
one, because $\mathrm{Tr}[(J^{\mathcal U})^2]=d^2$. For qubits, $d=2$ and hence
$1/d^2=1/4$. Averaging over $U$ and writing the link product as an ordinary
trace transposes each slot Choi operator, so

```math
F_{\mathrm{ave}}(\bar C)
=\mathrm{Tr}\!\left\{
\bar C\,\frac14\mathbb{E}_U\!\left[
\bigl((1-\gamma)\Phi_U+\gamma D\bigr)^{\otimes3}
\otimes J^{\mathcal U}\right]\right\}.
```

Expanding the third tensor power gives eight terms. A term containing exactly
$r$ factors $D$ has coefficient $\gamma^r(1-\gamma)^{3-r}$, and there are
$\binom{3}{r}$ possible positions for those factors.

The four matrices $\Omega_k^{(r)}$ are defined directly by

```math
\begin{aligned}
G^\dagger\!\left[\frac14\mathbb{E}_U
 (\Phi_U\otimes\Phi_U\otimes\Phi_U\otimes J^{\mathcal U})\right]G
&=\bigoplus_{k=0}^{8}(I_{d_k}\otimes\Omega_k^{(0)}),\\
G^\dagger\!\left[\frac1{12}\mathbb{E}_U
 \bigl((D\otimes\Phi_U\otimes\Phi_U
 +\Phi_U\otimes D\otimes\Phi_U
 +\Phi_U\otimes\Phi_U\otimes D)\otimes J^{\mathcal U}\bigr)\right]G
&=\bigoplus_{k=0}^{8}(I_{d_k}\otimes\Omega_k^{(1)}),\\
G^\dagger\!\left[\frac1{12}\mathbb{E}_U
 \bigl((D\otimes D\otimes\Phi_U
 +D\otimes\Phi_U\otimes D
 +\Phi_U\otimes D\otimes D)\otimes J^{\mathcal U}\bigr)\right]G
&=\bigoplus_{k=0}^{8}(I_{d_k}\otimes\Omega_k^{(2)}),\\
G^\dagger\!\left[\frac14\mathbb{E}_U
 (D\otimes D\otimes D\otimes J^{\mathcal U})\right]G
&=\bigoplus_{k=0}^{8}(I_{d_k}\otimes\Omega_k^{(3)})
=\frac{I_{256}}{64}.
\end{aligned}
\qquad (1)
```

The first three tensor factors act on the three slots and $J^{\mathcal U}$
acts on $PF$. For $r=1,2$, the three placements are averaged, which explains
$1/12=(1/4)/3$ in (1). Finally,

```math
\mathrm{Tr}\!\left[
(I_{d_k}\otimes\Omega_k^{(r)})
(I_{d_k}\otimes H_k)\right]
=d_k\,\mathrm{Tr}(\Omega_k^{(r)}H_k).
```

Combining the eight expansion terms therefore gives

```math
F_{\mathrm{ave}}(\bar C)
=\sum_{r=0}^{3}\binom{3}{r}\gamma^r(1-\gamma)^{3-r}
\sum_{k=0}^{8}d_k\,\mathrm{Tr}(\Omega_k^{(r)}H_k).
\qquad (2)
```

## 2. Full-ICO and $S_3$ equalities

Deterministic full-ICO normalization is

```math
\begin{cases}
C\succeq0,\\
\displaystyle
\sum_{S'\subseteq S}(-1)^{|S'|}
{}_{I_{\bar S}O_{\bar S}O_{S'}F}C=0
&\text{for every nonempty }S\subseteq\{1,2,3\},\\
{}_{I^3O^3F}C={}_{PI^3O^3F}C,\\
\mathrm{Tr}(C)=16.
\end{cases}
\qquad (3)
```

Covariance and complete-slot $S_3$ averaging preserve feasibility and the
objective. [v3_ICO_S3_constraints.txt](v3_ICO_S3_constraints.txt) contains the
resulting affine equalities for the blocks $H_k$ in solved form.

## 3. The displayed matrices are the certificate

[v3_CERTIFICATE_MATRICES.md](v3_CERTIFICATE_MATRICES.md) displays all
$d_k\Omega_k^{(r)}$ and $Q_k^{(r)}$ needed for $r=1,2$. Set

```math
\beta_1=\frac{21+8\sqrt{2}}{36},
\qquad
\beta_2=\frac{27+8\sqrt{2}}{72}.
```

For every $H_k$ satisfying the complete affine system, the certificate is
exactly

```math
Q_k^{(r)}\succeq0,
\qquad
\beta_r-\sum_{k=0}^{8}d_k\,
\mathrm{Tr}(\Omega_k^{(r)}H_k)
=\sum_{k=0}^{8}\mathrm{Tr}(Q_k^{(r)}H_k),
\qquad r=1,2.
\qquad (4)
```

Each whole nine-block identity in (4) can be checked by substituting
the full affine system. The conditions $Q_k^{(r)}\succeq0$ can be checked
directly from the displayed exact matrices using symbolic arithmetic.

Since $H_k\succeq0$, equation (4) proves

```math
\sum_{k=0}^{8}d_k\,\mathrm{Tr}(\Omega_k^{(1)}H_k)\leq\beta_1,
\qquad
\sum_{k=0}^{8}d_k\,\mathrm{Tr}(\Omega_k^{(2)}H_k)\leq\beta_2.
\qquad (5)
```

## 4. Combine the four noise-count terms

The two endpoint terms satisfy

```math
\sum_{k=0}^{8}d_k\,\mathrm{Tr}(\Omega_k^{(0)}H_k)\leq1,
\qquad
\sum_{k=0}^{8}d_k\,\mathrm{Tr}(\Omega_k^{(3)}H_k)=\frac14.
```

The first is the fidelity bound for the valid output channel obtained from
three ideal calls. The second follows from the exact full-matrix identity
for the all-depolarizing term and $\mathrm{Tr}(\bar C)=16$.
Substituting these endpoint facts and (5) into (2) gives

```math
\begin{aligned}
F_{\mathrm{ave}}(\bar C)
&\leq(1-\gamma)^3
+3\gamma(1-\gamma)^2\beta_1
+3\gamma^2(1-\gamma)\beta_2
+\frac{\gamma^3}{4}\\
&=\frac{2-\gamma}{24}
\left[12+(8\sqrt{2}-9)\gamma+(3-8\sqrt{2})\gamma^2\right].
\end{aligned}
\qquad (6)
```

This proves the full-ICO upper bound. The manuscript's parallel
encoder--decoder supplies the matching lower bound.
